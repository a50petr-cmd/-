# Копилка

Телеграм-бот, который записывает траты и спорит, когда хочется потратить крупное. Первая версия — чат, а не банк: деньги никуда не переводятся, Сбер и Т-Банк не вызываются, SMS и push не читаются.

Округление вверх до 100 ₽ кладётся в виртуальную копилку. Это записная книжка, не платёж.

## Что умеет

- Фраза «купил бургер за 450» или «потратил 500 на такси»: категория, какой это раз за неделю, остаток недельного бюджета, округление в копилку.
- Стоп-кран «хочу купить PS5 за 60к». Если цена больше 10% зарплаты — часы работы и пауза 24 часа. ДА / НЕТ. Ровно 10% порог не включает.
- Повтор одной и той же суммы примерно раз в месяц — текст дайджеста. Ссылка на отписку только та, которую вы сами сохранили.
- Семь суток без выбранной категории. Трата в ней обнуляет срок.
- Подсказка, какой своей картой платить, по процентам, которые вы ввели.
- На старте бот спрашивает зарплату, бюджет на неделю и часовой пояс. Молчание про пояс значит `Europe/Moscow`.

## Чего здесь нет

Живых API банков, настоящих переводов округления, перехвата SMS и push. Это сознательно не первая версия.

## Запуск

Нужны Python 3.11+ и Docker.

```bash
docker compose up -d
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m kopilka
```

Токен берётся у [@BotFather](https://t.me/BotFather) и кладётся в `.env`. Postgres из compose слушает `localhost:5432`. Пароль в `docker-compose.yml` годится только для локальной машины. Если бот стартовал раньше, чем база приняла соединения, запустите `python -m kopilka` ещё раз.

Бот работает через long polling, вебхук не нужен.

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота. Без него процесс не стартует. |
| `DATABASE_URL` | Строка SQLAlchemy. Локально: `postgresql+psycopg://kopilka:kopilka@localhost:5432/kopilka` |

## Как пользоваться

После `/start`:

- `купил бургер за 450` — записать трату
- `потратил 500 на такси` — то же, другой порядок слов
- `хочу купить PS5 за 60к` — стоп-кран
- `ДА` / `НЕТ` или кнопки под сообщением
- `бюджет` и `бюджет 7000` — остаток или новый лимит
- `зарплата 120000`
- `копилка` — сумма виртуальных округлений
- `траты`
- `челлендж такси` и `челлендж` — старт и статус
- `карта зарплатная`
- `кэшбэк зарплатная продукты 5`
- `подсказка продукты`
- `подписки` и `дайджест`
- `отписка Кинопоиск https://example.com`
- `пояс Europe/Moscow`
- `категории`

Те же действия есть командами `/help`, `/week`, `/piggy`, `/expenses`, `/challenge`, `/digest`, `/subs`, `/cards`, `/hint`. В меню Telegram команды на латинице: так устроены слэш-команды.

Неделя считается с понедельника в вашем часовом поясе. Бюджет уменьшается на фактическую сумму, не на округлённую. 450 ₽ дают 50 ₽ в копилку и минус 450 ₽ из недели. Сумма, уже кратная 100, в копилку не попадает.

Часы работы: цена ÷ (зарплата / 160). 160 часов в месяц в этой версии не меняются.

Подписка — это одно и то же название и одна сумма минимум два раза, с паузой 25–35 дней. Дайджест приходит по команде и один раз 1-го числа, если в этот день вы написали боту.

## Тесты

База и токен не нужны.

```bash
pytest
```

Проверяются разбор фраз, округление до 100 ₽, порог 10% и пауза суток, поиск повторных списаний.

## Как устроено

- `kopilka/parsing.py`, `kopilka/money.py`, `kopilka/recurring.py` — правила без Telegram и без базы
- `kopilka/repo.py` — PostgreSQL через SQLAlchemy
- `kopilka/handlers/` — диалог на aiogram 3
